# User manual

The manuals for uConsole for DSPi: the desktop app, the web console, Android and the Terminal (`uconsole`).
Help › User Manual opens this page.

- [Installing](../INSTALL.md): every platform, USB access on Linux, the layout and AI agents after installing.
- [Words the app uses](words.md): what the words on the screens mean.
- [Measuring and auto-tune](measurement.md): placing the microphone, the safety rules, auto-tune and its trial.
- [AI agents](ai-agents.md): connecting Claude and other agents, what they may do, questions, watching and undoing.
- [Notices](notices.md): firmware versions, hubs and updates.

In the app, Ctrl+K finds a page, a setting or a command by the words you type, and its "Help: …" entries open the
section of these pages that answers.
