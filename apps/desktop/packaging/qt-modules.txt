# The Qt modules the desktop app needs, in one place (-- WP QPI4 --). Read by
# qt/CMakeLists.txt (link), qt/cmake/wp/qp20.cmake (import, package: the .deb's
# Depends, and a configure-time check that every module qt/qml imports is
# listed) and the two deploy scripts, windows/deploy-mingw.sh and
# linux/make-appimage.sh (runtime). What each image installs is pinned apart,
# in licences/qt-modules.sh; the plugin lists in the deploy scripts differ by
# platform and stay there.
#
#   link <component>           a Qt6 component both targets link (Linux adds DBus)
#   import <module> <package>  a QML module qt/qml imports, and its Debian package
#   package <package>          another Debian package the app loads at run time
#   runtime <qml dir>          a QML module Controls.Basic loads at run time,
#                              beside what qmlimportscanner finds
