# QP12: Control Surfaces, Channel Groups, Macros, Auxiliary Outputs

Section: `qp12-surfaces` (order 47). A record's key is `binding/<slot>`, `ir/<sub>`, `group/<n>` or `macro/<n>`; its
object name is `Cs.` and the key with `.` for `/` (`Cs.binding.3`, `Cs.ir.0`).

| Name | What |
|---|---|
| `SurfacesPage`, `GroupsPage`, `MacrosPage`, `AuxPage` | the four pages |
| `Cs.reading`, `Cs.loadError` | the line while the tables are read, and a failed read |
| `Cs.controls.empty`, `Cs.aux.empty`, `Cs.groups.empty`, `Cs.macros.empty` | a list's empty state |
| `Cs.controls.add`, `Cs.controls.addEmpty`, `Cs.aux.add`, `Cs.aux.addEmpty` | "Add Control" / "Add Output"; `.menu`, `.menu.type.<n>` |
| `Cs.groups.add`, `Cs.groups.addEmpty`, `Cs.macros.add`, `Cs.macros.addEmpty` | "Add Group" / "Add Macro" |
| `Cs.<key>` | a card |
| `Cs.<key>.disclose`, `.name`, `.summary`, `.pill` (`.pill.text`), `.remove`, `.typeMenu` | the card's header |
| `Cs.<key>.applyRow` (`.text`, `.revert`, `.apply`) | its Apply row; `.text` is the refusal or the hint |
| `Cs.<key>.rows` | the rows the core describes; each `….row.<id>` with `.combo`, `.spin` or `.switch` |
| `Cs.<key>.inactive` | why a stored control is not running |
| `Cs.binding.<n>.auxOn` (`.switch`), `Cs.binding.<n>.auxLevel` | an aux output's live switch and level |
| `Cs.binding.<n>.addRemote` | the receiver's "Add Remote Button" |
| `Cs.remotes.count` | "n/16" over the remote buttons |
| `Cs.ir.<n>.disclose`, `.code`, `.learn`, `.remove`, `.learnMessage`, `.rows`, `.message` | a remote button |
| `Cs.display.state`, `Cs.display.message`, `Cs.display.rows`, `Cs.display.addPage` | the display card's panel state, settings and pages |
| `Cs.page.<n>` (rows), `Cs.page.<n>.remove` | a dashboard page |
| `Cs.group.<n>.rows.row.member.<ch>.check` | a group's member check box |
| `Cs.macro.<n>.run`, `.addStep`, `.step.<s>` (rows), `.step.<s>.summary`, `.step.<s>.remove` | a macro's run button and steps |
