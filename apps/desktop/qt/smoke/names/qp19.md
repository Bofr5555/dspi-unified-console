# QP19: the smoke driver's launches and the gallery

Sections: `qp19-gallery` (900, main run), `qp19-slider-keys` (15, main run), `qp19-demo-entry` (DemoEntry),
`qp19-tray-launch` (Tray), `qp19-hw-*` (Hardware), `qp19-replug` (Replug), `qp19-selftest` (SelfTest, by hand).
NAMES.md lists every section and its launch.

No new object names. The sections use these of other packages:

| Name | Owner | Used for |
|---|---|---|
| `SmokeProbeWindow.slider` | QP0 | the slider keys |
| `DevicesPopup`, `DevicesPopup.demo` | QP13 | the demo offered and chosen with nothing connected; the gallery's device list |
| `Tray.open`, `Tray.quit` (QActions of the tray menu) | QP14 | the tray launches |
| `SettingsWindow` and `SettingsController.sidebarRows("")` | QP10 | the gallery's walk of every page shown |
| every `Registrar::Window` (action → type) | each package | the gallery opens each from its menu action |

Files the run writes:

| File | What |
|---|---|
| `gallery/<window>-dark.png`, `gallery/<window>-light.png` | every tool window by its type without "Window" (`autoeq`, `crossfeed`, ...), `main`, `devices`, and `settings-<page id>` |
| `index.html` | the gallery's pairs, then every other PNG of the run and its launches |
| `demo-entry/window-disconnected.png`, `window-demo-offered.png`, `window-demo-active.png` | QD7 |
| `tray-hidden/window-main.png`, `tray-no-tray/window-main.png` | the window after Open, and with no tray |
| `hw-dry/window-main.png` | the hardware pass's end |
| `cycle-<n>-unplugged.png`, `cycle-<n>-replugged.png` | the replug pass |
