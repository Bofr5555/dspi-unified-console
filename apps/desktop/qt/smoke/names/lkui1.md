# Object names: LKUI1 (the audio link's installation on a hub)

| Name | What |
|---|---|
| `Menu.window.system` | Window > System… |
| `SystemWindow` | the System window |
| `SystemWindow.none` | the line shown while not on a hub |
| `SystemWindow.summary`, `SystemWindow.role` | the status line and the hub's role |
| `SystemWindow.scenes`, `SystemWindow.scene.<scene id>` | the scene bar and a scene's button |
| `SystemWindow.recallNote`, `SystemWindow.recallResult` | why recalling is not offered; the last recall's words |
| `SystemWindow.units`, `SystemWindow.unit.<id>` | the units table and a row; `shownName` (name, state) |
| `SystemWindow.editNote`, `SystemWindow.editor` | the read-only note and the Clock-and-audio-links fields |
| `SystemWindow.delayAuto`, `SystemWindow.delayFrames` | the system delay |
| `SystemWindow.lipSync.<room id>`, `SystemWindow.latency.<unit id>` | a room's lip sync, a unit's measured latency |
| `SystemWindow.stale`, `SystemWindow.save`, `SystemWindow.reload`, `SystemWindow.align` | the stale warning and the editor's buttons |
| `SystemWindow.actionMessage`, `SystemWindow.alignQuestion` | the last Save's or alignment's words; the question before writing |
| `SystemStatusStrip`, `SystemStatusStrip.summary`, `SystemStatusStrip.open` | the status line under the menu bar; `shownName` |
