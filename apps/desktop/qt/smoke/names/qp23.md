# Object names: QP23 (the Core Voltage page)

Section: `qp23-vreg` (order 100, `smoke/SmokeCoreVoltage.cpp`). It runs only on the demo device and plays the
flow's states with the core's demo hooks (`dspi_core_vreg_demo_event`). Screenshots, each also as `-light`:
`settings-core-voltage-<state>.png` for idle, review, confirm-word, soaking, passed, committed, failed,
hardware-problem, unknown, trial-found; `settings-core-voltage-stock.png` is Advanced without the extension.

| Name | What |
|---|---|
| `CoreVoltagePage` | the page (Settings page `coreVoltage`, group Hidden; `trialCode`, `manualCode`, `soakS`, `pending`) |
| `CoreVoltage.back` | Back to Advanced |
| `CoreVoltage.warning`, `CoreVoltage.warningText` | the core's warning |
| `CoreVoltage.device` | On the Device |
| `CoreVoltage.running`, `.saved`, `.default`, `.autoState`, `.hangs`, `.lastFailed` (each `.value`) | its rows |
| `CoreVoltage.calibrate` | Calibrate |
| `CoreVoltage.state` (`.value`), `CoreVoltage.message`, `CoreVoltage.linkLost`, `CoreVoltage.error` | the state's name, the core's description, a lost link, the core's last refusal |
| `CoreVoltage.soak`, `CoreVoltage.progress`, `CoreVoltage.abort` | the soak's row: elapsed of total, Abort |
| `CoreVoltage.trialVoltage`, `CoreVoltage.soakTime` (each `.combo`) | the pickers |
| `CoreVoltage.begin`, `.start`, `.keep`, `.commit`, `.endTrial`, `.close` | Calibrate…, Start…, Keep…, Save…, End Trial, Close |
| `CoreVoltage.confirm` | the Confirm block |
| `CoreVoltage.confirmText`, `CoreVoltage.wordPrompt`, `CoreVoltage.word` | what is asked, the word prompt, the word field |
| `CoreVoltage.confirmButton`, `CoreVoltage.cancel` | Confirm, Cancel |
| `CoreVoltage.manual` | Manual |
| `CoreVoltage.manualVoltage` (`.combo`) | the voltage picker |
| `CoreVoltage.manualTrial`, `.manualSave`, `.manualReset`, `.manualAuto`, `.manualClear` | Trial…, Save…, Reset…, Turn On…/Turn Off…, Clear… |

The entry on Advanced keeps QP10's names (`Advanced.coreVoltage`, `Advanced.coreVoltageOpen`).
