# Object names: QP10 (Settings window and its application pages)

Section: `qp10-settings` (order 40, `smoke/SmokeSettings.cpp`).

| Name | What |
|---|---|
| `SettingsWindow` | the Settings window (Edit > Settings..., Help > About) |
| `Settings.search`, `Settings.searchClear` | the search field and its clear button |
| `Settings.noMatch` | the "no matching settings" line |
| `Settings.sidebar` | the page list |
| `Settings.heading` | a group heading row |
| `Settings.row.<page id>`, `Settings.button.<page id>` | a page's row and its button |
| `Settings.back`, `Settings.forward`, `Settings.title`, `Settings.close` | the title row |
| `Settings.page` | the loader of the page showing |
| `AboutPage`, `AdvancedPage`, `GraphingPage`, `SpectrumPage`, `UpdatesPage`, `OverviewPage` | the pages |
| `About.name`, `About.version`, `About.credit.<n>`, `About.project`, `About.link.<link id>` | About's header and links |
| `About.notices`, `About.notice.<n>` | the notices section and each notice row |
| `About.viewer`, `About.viewerTitle`, `About.viewerText`, `About.viewerClose` | the notice viewer |
| `Advanced.resetNames`, `Advanced.debug` (`.switch`), `Advanced.device`, `Advanced.firmware` (`.value`) | Advanced |
| `Advanced.coreVoltage`, `Advanced.coreVoltageOpen` | the Core Voltage entry (shown once a `coreVoltage` page is registered) |
| `Graphing.<key>` | each Graphing row, by its `graph/` key; a switch row's switch is `.switch`, a slider's `.slider`, a picker's `.combo` |
| `Spectrum.<key>` | each Spectrum Analyser row, by its `spectrum/` key, with the same suffixes |
| `Updates.status`, `Updates.detail`, `Updates.checkNow`, `Updates.automatic` (`.switch`), `Updates.privacy` | Updates |
| `Updates.availableCard`, `Updates.notes`, `Updates.skip`, `Updates.skipQuestion`, `Updates.viewRelease` | the Available card |
| `Overview.coreVoltage`, `Overview.coreVoltageRefresh`, `Overview.running` (`.value`) | the core voltage block |
| `Overview.disconnected`, `Overview.summary`, `Overview.inUse`, `Overview.pinGrid`, `Overview.legend` | the map |
| `Overview.noneHeld`, `Overview.role.<0..4>` | the held pins by role (outputs, clocks, inputs, control, other) |
| `SmokeSettingsPage`, `SmokeSettingsSection`, `SmokeSettingsFooter` | the smoke build's probe page (`smokeprobe`), section (on Advanced) and footer |
