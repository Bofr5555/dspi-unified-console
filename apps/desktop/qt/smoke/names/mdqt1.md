# WP MDQT1: several open devices

| Name | What |
|---|---|
| `DevicesPopup.openHeading` | the "Open devices" heading, shown with more than one device open |
| `DevicesPopup.open.<id>` | one open device's row (`current`: the active one); `<id>` as in `DeviceRegistry.devices` |
| `DevicesPopup.close.<id>` | its Close button |
