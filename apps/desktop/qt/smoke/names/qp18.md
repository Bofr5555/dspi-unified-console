# Object names: QP18 (polish across the tree)

Sections: `qp18-polish` (order 180, `smoke/SmokePolish.cpp`), `qp18-access` (order 190, `smoke/SmokeAccess.cpp`) and
`qp18-pseudo` (`smoke/SmokeAccess.cpp`: the pseudo launches' section where the driver has them, `DSPI_SMOKE_PSEUDO=en`
then `=pseudo`; otherwise order 195 in the main pass). `smoke/Qp18Notices.h` lets a section take a success's notice.
