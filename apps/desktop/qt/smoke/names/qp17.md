# Object names: QP17 (onboarding, About's licence block, updates)

Sections: `qp17-onboarding` (order 160, `smoke/SmokeOnboarding.cpp`) and `qp17-updates` (order 170,
`smoke/SmokeUpdates.cpp`).

| Name | What |
|---|---|
| `MainWindow.wizard` | the main window's loader of the wizard (`item` is null while the console shows) |
| `GettingStarted` | the wizard, in the console's place (`current`, `confirmed`) |
| `GettingStarted.counter`, `GettingStarted.steps` | "Step n of m" and the step dots |
| `GettingStarted.title`, `GettingStarted.paragraph`, `GettingStarted.row` | the step's title, its paragraphs and rows |
| `GettingStarted.card`, `.cardTitle`, `.cardText`, `.cardAction` | the board step's card and its button |
| `GettingStarted.tryAgain` | Try Again after a failed install |
| `GettingStarted.skip`, `GettingStarted.back`, `GettingStarted.continue` | the footer (`continue` is also the last step's button) |
| `WhatsNewWindow` | the What's New window (`help.whatsNew`) |
| `WhatsNew.list` (`count`), `WhatsNew.release.<n>`, `WhatsNew.headline`, `WhatsNew.item`, `WhatsNew.empty`, `WhatsNew.done` | its contents |
| `HelpHost`, `HelpHost.notice` | the main window's alert for Help's messages (Save Diagnostics) |
| `About.licence` | About's licence block |
| `About.licenceCopyright`, `About.licenceStatement`, `About.licenceGpl`, `About.licenceNotices`, `About.licenceTerm.<term id>` | its parts |
| `Advanced.onboarding`, `Advanced.resetOnboarding`, `Advanced.onboardingState` | Advanced > Onboarding (Developer) |
| `UpdateBanner`, `UpdateBanner.details`, `UpdateBanner.later` | the update banner |
| `Menu.help.saveDiagnostics` | Help > Save Diagnostics... (hidden until the core has the bundle) |

The Updates page's own names are QP10's (`Updates.*`, `names/qp10.md`).
