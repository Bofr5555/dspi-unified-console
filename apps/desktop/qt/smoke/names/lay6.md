# Object names: LAY6 (the command palette)

Smoke section: `lay6-palette` (order 898, `smoke/SmokeLay6.cpp`). Screenshots `gallery/lay6-<width>-<all|save|line>-<scheme>.png`.

- `CommandPalette` (the popup: `entries`, `rows`), `.field`, `.list`, `.none` (nothing found).
- `CommandPalette.row.<entry id>` with `.title`, `.where`, `.keys`. An entry's id: a MenuTable id, `section:<id>`, `page:<section>/<tab>`,
  `channel:<wire channel>`, `settings:<page id>`, `device:<device id>`.
- `TopBar.search` opens it now; `TopBar.search.keys`.
