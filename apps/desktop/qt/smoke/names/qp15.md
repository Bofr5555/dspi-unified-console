# WP QP15: Files and AutoEQ

Sections: `qp15-files` (order 150, `smoke/SmokeFiles.cpp`) and `qp15-autoeq`
(order 151, `smoke/SmokeAutoEq.cpp`). Screenshots: `window-files-import-filters`,
`window-files-import-config`, `window-files-unsaved`, `window-autoeq`,
`window-autoeq-update`, `window-autoeqRebuild`.

| Name | What |
|---|---|
| `FilesHost` | the main window's host of the File and AutoEQ dialogs (`FilesController.host()`) |
| `FilesHost.notice` | the alert after a file action (`title`, `text`, `error`) |
| `NoticeDialog.text`, `NoticeDialog.ok` | its text and its button |
| `ImportFilters` | Import Filters' channel picker (`prompt`, `channels`, `setTicked(wire, on)`) |
| `ImportFilters.prompt` | what the file holds |
| `ImportFilters.channel.<wire>` | a channel's check box (in the dialog's `contentItem`) |
| `ImportFilters.import`, `ImportFilters.cancel` | its buttons |
| `ImportConfig` | Import Device Configuration's options (`prompt`) |
| `ImportConfig.prompt`, `ImportConfig.volumes`, `ImportConfig.hardware` | the prompt and the two check boxes |
| `ImportConfig.import`, `ImportConfig.cancel` | its buttons |
| `ImportProgress` | the sheet while a configuration is written |
| `FilesHost.unsavedQuestion` | the unsaved-changes question of a device switch, quit and close (a `QuestionDialog`) |
| `FilesHost.saveFailedQuestion` | "Quit anyway?" after a failed save |
| `FilesHost.rebuildQuestion` | Rebuild AutoEQ Database's confirmation |
| `AutoEqUpdateDialog` | AutoEQ > Update Database... (`text`) |
| `AutoEqUpdateDialog.rebuild`, `.import`, `.reset`, `.cancel` | its four answers (`.reset` only with a user database) |
| `AutoEqWindow` | the AutoEQ browser (a top-level window; `selectedId`, `applySelected()`) |
| `AutoEqWindow.search`, `AutoEqWindow.clearSearch` | the search field and its clear button |
| `AutoEqWindow.list`, `AutoEqWindow.row.<n>`, `AutoEqWindow.favorite.<n>` | the list, a row, a row's heart |
| `AutoEqWindow.empty` | the text while nothing is listed |
| `AutoEqWindow.selectedName`, `AutoEqWindow.cancel`, `AutoEqWindow.apply` | the bottom bar |
| `AutoEqRebuild` | the Updating Database window (top-level) |
| `AutoEqRebuild.progress`, `AutoEqRebuild.status`, `AutoEqRebuild.cancel` | its bar, status line and Cancel |
| `Menu.autoeq.favorite.<n>` | a favourite in AutoEQ > Favorite Profiles |
| `Menu.autoeq.noFavorites` | "No favorites yet", while there is none |

The file dialog is a `QFileDialog`: `FilesController::openDialog()` gives the open one.
