# Object names: QP13 (devices and Link)

| Name | What |
|---|---|
| `DevicesHost` | the main window's holder of the device list and the pairing prompt (`DevicesController.host()`) |
| `DevicesPopup` | the device list (a popup; `opened`) |
| `DevicesPopup.done` | its Done button |
| `DevicesPopup.usb.<serial>` | a DSPi on USB; `current` when open |
| `DevicesPopup.demo` | the demo device; `current` when open |
| `DevicesPopup.phaseText` | the Link session's status line (the core's sentence, after the hub's name) |
| `DevicesPopup.phaseAction` | the phase's button (the core's, else Disconnect) |
| `DevicesPopup.retry` | Retry Now, while reconnecting |
| `DevicesPopup.hubDevice.<serial>` | a hub's device; `current` when bound; disabled while reconnecting |
| `DevicesPopup.error` | the last Link failure, in the core's words |
| `DevicesPopup.lookForHubs` | Find hubs automatically |
| `DevicesPopup.foundHub.<hub id>` | a hub found on the network |
| `DevicesPopup.browseStatus` | the line shown while no hub is listed |
| `DevicesPopup.address`, `DevicesPopup.connect` | the address field and its Connect button |
| `PairingDialog` | the pairing prompt (a dialog; `opened`, `submit()`) |
| `PairingDialog.text`, `.pin`, `.error`, `.pair`, `.cancel` | its text (the core's), the PIN field, the error line, its buttons |
| `LinkBanner`, `LinkBanner.disconnect` | the lost-connection banner and its button |
| `LockNotice` | the banner while another console holds the hub's device |
| `TokenNotice`, `TokenNotice.ok` | the banner when a pairing went to the file, and its OK |
