# Object names: QP11 (hardware settings pages and the save bar)

Section: `qp11-hardware` (order 45, `smoke/SmokeHardware.cpp`).

A picker (`ChoicePicker`, `PinPicker`) is driven through its `activated(index)`
signal over its `shown` list; a `SettingsToggle`'s switch is `<name>.switch`; a
`NameField`'s text field is `<name>.field`, its clear button `<name>.clear`.

| Name | What |
|---|---|
| `SaveBar` | the save bar (a registered footer) |
| `SaveBar.title`, `SaveBar.subtitle` | its two lines |
| `SaveBar.failure` | the orange line naming what a Save could not write (QD31) |
| `SaveBar.held` | the orange line while the device has not applied the latency |
| `SaveBar.revert`, `SaveBar.save` | its buttons |
| `GlobalPage` | Global Parameters |
| `Global.deviceName`, `Global.name` | the Device Name group and its name field |
| `Global.latency`, `Global.latencyTarget`, `Global.latencyCaption` | the Latency card |
| `Global.powerOn` | the "At power-on" heading |
| `Global.startup`, `Global.startupMode`, `Global.defaultSlot` | Startup Preset |
| `Global.masterVolume`, `Global.masterVolumeMode` | Master Volume |
| `Global.outputConfig`, `Global.outputConfigMode` | Hardware Configuration |
| `Global.mute`, `Global.muteEnabled`, `Global.mutePolarity`, `Global.mutePin`, `Global.muteHold`, `Global.muteRelease`, `Global.muteTest` | External Mute Control |
| `OutputsPage` | Outputs |
| `Outputs.slots`, `Outputs.row.<id>`, `Outputs.default.<id>`, `Outputs.type.<id>`, `Outputs.pin.<id>` | the slots; `<id>` is the output (the sub is 4, or 2 on the RP2040) |
| `Outputs.adat`, `Outputs.adatEnabled`, `Outputs.adatPin` | Bulk Output |
| `Outputs.status`, `Outputs.resetPins` | the status line and Reset Pins |
| `I2sPage` | I2S Configuration |
| `I2s.clock`, `I2s.bckPin`, `I2s.clockPins`, `I2s.slaveBckPin`, `I2s.mck`, `I2s.mckPin`, `I2s.mckMultiplier`, `I2s.inputRate`, `I2s.status` | its rows |
| `InputsPage` | Inputs |
| `Inputs.spdif`, `Inputs.spdifCount`, `Inputs.spdifPin.<n>`, `Inputs.lg`, `Inputs.status` | S/PDIF Input |
| `Inputs.i2s`, `Inputs.i2sClockMode`, `Inputs.i2sLock`, `Inputs.i2sChannels`, `Inputs.i2sPin.<pair>`, `Inputs.unusedPairs`, `Inputs.clockQuestion` | I2S Input |
| `Inputs.adat`, `Inputs.adatEnabled`, `Inputs.adatPin`, `Inputs.adatClockMode`, `Inputs.adatFreeRunning`, `Inputs.enableAdatOut`, `Inputs.adatLock` | ADAT Input |
| `Inputs.names`, `Inputs.name.<source>` | Source Names |
| `InterfacesPage` | Control Interfaces |
| `Interfaces.uart`, `Interfaces.uartEnabled` (`.pill`, `.switch`), `Interfaces.uartTx`, `Interfaces.uartRx`, `Interfaces.uartBaud`, `Interfaces.uartNotify`, `Interfaces.uartApply` (`.text`, `.revert`, `.apply`) | UART |
| `Interfaces.i2c`, `Interfaces.i2cEnabled` (`.pill`, `.switch`), `Interfaces.i2cSda`, `Interfaces.i2cScl`, `Interfaces.i2cAddress`, `Interfaces.i2cApply` (`.text`, `.revert`, `.apply`) | I2C |
