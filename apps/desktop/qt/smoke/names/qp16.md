# WP QP16: firmware, read-only, delay refusal, device access

Smoke sections: `qp16-firmware` (order 160, `smoke/SmokeFirmware.cpp`), `qp16-access` (161, same file),
`qp16-readonly` (165, `smoke/SmokeReadOnly.cpp`).

| Name | What |
|---|---|
| `FirmwareWindow` | the firmware window (`device.firmwareUpdate`), 460×470 |
| `FirmwareWindow.subtitle` | "Install firmware … onto a DSPi board" |
| `FirmwareWindow.summary` | the versions card |
| `FirmwareWindow.expected`, `.device`, `.image` | its rows; `value` is the text shown |
| `FirmwareWindow.imageChecked` | the image passed the core's check (and carries the expected version) |
| `FirmwareWindow.chooseImage`, `.useBundled` | Choose .uf2..., Use this Console's firmware instead |
| `FirmwareWindow.imageProblem` | why a custom image cannot be used |
| `FirmwareWindow.downgradeNote` | the device is newer: this would be a downgrade |
| `FirmwareWindow.steps` | Prepare, Write, Verify, Done |
| `FirmwareWindow.status`, `.statusIcon`, `.statusTitle`, `.statusMessage` | the installer's state card |
| `FirmwareWindow.writing` | the progress and the board while writing |
| `FirmwareWindow.bootselHint`, `.manualHint`, `.enterBootloader` | the BOOTSEL hint; the manual bootloader link |
| `FirmwareWindow.cancel`, `.export`, `.primary`, `.another`, `.done` | the buttons |
| `FirmwareWindow.guard` | the firmware guard's question (a Dialog: find it with `findChild`) |
| `FirmwareWindow.guardMessage`, `.guardTyped`, `.guardCancel`, `.guardGo` | its message, field, Don't Install, Go Ahead |
| `FirmwareBanner`, `FirmwareBanner.update`, `FirmwareBanner.hide` | the version-mismatch banner |
| `ReadOnlyBanner`, `ReadOnlyBanner.action` | the read-only banner; Update... or Details... |
| `DelayRefusalBanner` | the delay refusal; the core's sentence |
| `UdevDialog` | the device-access dialog (a Dialog in the main window) |
| `UdevDialog.text`, `.rule`, `.error`, `.close`, `.install` | its text, the rule's path, the failure, the buttons |
